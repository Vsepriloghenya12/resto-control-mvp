# Senior roles + TTK/service-book upload pass

## Роли
- Добавлены роли: старший официант, старший бармен, старший повар.
- Старшие сотрудники работают в мобильном приложении как сотрудники, но получают дополнительные пункты управления отделом.
- Старший официант управляет чек-листами и задачами зала.
- Старший бармен управляет чек-листами и задачами бара.
- Старший повар управляет чек-листами и задачами кухни.
- Менеджер сохраняет полный доступ к управлению рестораном.

## Чек-листы
- Старшие сотрудники могут создавать и редактировать шаблоны чек-листов только для ролей своего подразделения.
- Отчеты по выполнению чек-листов для старших сотрудников ограничены их подразделением.

## Задачи
- Старшие сотрудники могут создавать задачи для своей команды.
- При назначении задачи всем сотрудникам старшим сотрудником задача ограничивается его подразделением.
- При назначении по роли или конкретному сотруднику сервер проверяет принадлежность к подразделению.

## База знаний / ТТК / сервис-буки
- Добавлена загрузка PDF-документов.
- Добавлена загрузка сервис-буков в PDF.
- Добавлена загрузка ТТК в PDF с автоматическим разбором состава: ингредиент, количество, единица измерения.
- Если один PDF содержит несколько ТТК, приложение создает несколько документов.
- К ТТК можно прикрепить фото блюда или напитка.
- В карточке документа показываются ссылка на PDF, фото и разобранный состав.
