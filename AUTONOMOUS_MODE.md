# Автономный режим

Добавлен режим работы без POS/API-ключей.

## Логика

- Если API-логин iiko не введён, интеграция получает статус `autonomous`.
- Брони, смены, чек-листы, задачи, проблемы, база знаний и номенклатура работают локально внутри приложения.
- Проверка подключения и ручная сверка не падают с ошибкой при отсутствии ключа — сервер возвращает успешный ответ с сообщением, что синхронизация пропущена.
- Внешние API не вызываются, пока не сохранён API-логин.
- Владелец может включить/оставить режим “Работать автономно без POS/API” в разделе `Интеграции`.

## Что изменено

- `server/index.js`
  - безопасный публичный статус интеграции по умолчанию;
  - сохранение автономного режима;
  - безопасные ответы `/test` и `/sync` без ключа.

- `webapp/src/App.tsx`
  - добавлен переключатель автономного режима;
  - внешние поля блокируются, если приложение работает без POS/API;
  - статус отображается как “автономно”.

- `webapp/src/styles.css`
  - компактное оформление примечания к режиму интеграции.
