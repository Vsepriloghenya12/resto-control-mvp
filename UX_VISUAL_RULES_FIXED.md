# Зафиксированные правила визуальной логики

1. Интерфейс должен быть компактным: меньше отдельных карточек, больше чистых строк и списков.
2. Списки по умолчанию свернуты, если это не рабочий список, который сотрудник заполняет прямо сейчас.
3. Если строка или заголовок раздела раскрывает список по нажатию, отдельная кнопка «Развернуть» не используется.
4. Дублирующие кнопки убираются: одно действие — одна очевидная точка входа.
5. Мобильные списки должны выглядеть как аккуратные строки с разделителями, без лишних обёрток и теней.
6. На экране оставляются только рабочие подписи и статусы, без обучающих пояснений у каждого блока.
7. Главные действия должны быть короткими и понятными: «Проблема», «Создать задачу», «Сохранить», «Удалить».
8. Если элемент можно открыть кликом по строке, строка сама является действием.
9. Важная информация остаётся в строке: название, количество, статус, время или ответственный.
10. Детали показываются только после раскрытия.
