# B2B-оплата для ИП

Добавлен правильный для ресторанов сценарий: счёт на оплату → оплата с расчётного счёта → отметка оплаты → продление доступа → закрывающий документ.

## В приложении ресторана

Раздел владельца: `Оплата`.

Внутри:
- реквизиты юрлица/ИП ресторана;
- формирование счёта по тарифу и периоду;
- скачивание счёта HTML, который можно печатать или сохранить как PDF;
- закрывающие документы после отметки оплаты.

## В кабинете создателя

Раздел: `Оплаты`.

Внутри:
- список счетов всех ресторанов;
- скачивание счёта;
- кнопка `Отметить оплату`.

После отметки оплаты:
- счёт становится `paid`;
- создаётся платёж;
- создаётся акт;
- ресторан получает активную подписку до конца оплаченного периода.

## Реквизиты исполнителя

Заполните переменные окружения `BILLING_SELLER_*` из `.env.example`.

Для ИП обычно используется `BILLING_SELLER_OGRNIP`, `BILLING_SELLER_INN`, расчётный счёт и банковские реквизиты.
