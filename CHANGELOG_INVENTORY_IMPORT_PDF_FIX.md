# Inventory PDF import fix

- Исправлен импорт PDF-бланков инвентаризации с табличной версткой, где код, наименование, штрихкод, группа и единица измерения могут попадать в текст без пробелов или на разные строки.
- PDF-парсер теперь ищет товарные строки по коду товара, собирает многострочное наименование и определяет единицу измерения даже в форматах вроде `01456Бодуен VSпорцКОНЬЯК/БРЕНДИ`, `01414...л486...`, `02102 ... л`.
- Добавлена очистка штрихкодов, заголовков таблицы, номеров страниц и групп после единицы измерения.
- Мобильный заголовок вкладок очищен: на обычных вкладках больше не выводится название вкладки и заведения, полезный контент начинается выше.

Проверки:
- `npm run build --workspace webapp`
- `node --check server/index.js`
- `node --check server/db.js`
