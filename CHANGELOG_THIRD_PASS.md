# Third UX / booking / inventory pass

## Бронирование столов
- Сотрудник может нажать на свободный стол и выбрать действие:
  - `Занято` — стол сразу получает статус занят / гости сели без брони.
  - `Создать бронь` — открывается форма брони на выбранный стол.
- Для занятого стола в карточке брони появилась кнопка `Свободен` — она завершает текущую посадку и освобождает стол.
- Для существующей брони появилась кнопка `Занято` — сотрудник может отметить, что гости пришли и сели.
- Добавлены API endpoints:
  - `POST /api/bookings/tables/:id/seat`
  - `POST /api/bookings/tables/:id/free`
- Статусное изменение брони до `seated`/`completed` разрешено любому сотруднику, а не только создателю брони.

## Инвентаризация
- Мобильный список товаров для сотрудника переделан из карточек в простой список с разделительными линиями.
- Поле количества теперь занимает всю строку под названием товара и единицей измерения.
- Поле количества принимает выражения с плюсом и десятичной запятой: `3+2,2+0,04`.
- На сервере выражение считается при сохранении, например `3+2,2+0,04` сохраняется как `5.24`.
- Excel-экспорт теперь делает общий файл по бланку и дате: если два сотрудника посчитали один товар, их значения суммируются в строке `Итого`.
- В Excel добавлены участники подсчёта и исходные выражения по сотрудникам в колонке `Подсчёты`.
