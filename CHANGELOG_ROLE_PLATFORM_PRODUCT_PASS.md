# Role/platform product pass

- Разделена архитектура рабочих режимов по ролям:
  - владелец: только ПК-кабинет с настройками ресторана;
  - менеджер: ПК + мобильный операционный кабинет;
  - сотрудники: только мобильный интерфейс.
- Для менеджера обзор переименован и перестроен как «Пульт смены»: задачи, заявки, чек-листы, проблемные места смены.
- Для владельца обзор переориентирован на настройки ресторана: сотрудники, чек-листы, номенклатура, залы, документы, подписка.
- Сотрудники на ПК теперь получают тот же мобильный рабочий интерфейс в мобильной ширине, без десктопной навигации.
- Мобильная версия владельца не получает нижнюю мобильную навигацию и сохраняет ПК-рабочий кабинет.
- Импорт бланков инвентаризации у владельца переведён в безопасный двухшаговый сценарий:
  1. Проверить бланк и увидеть предпросмотр найденных позиций.
  2. Добавить только новые позиции в ассортимент.
- Серверный импорт инвентаризации получил режим `dry_run`, который возвращает новые позиции и дубли без сохранения.
- Добавлен предпросмотр импорта: найдено / новых / дублей, список первых позиций и статусы «добавится» / «уже есть».

Проверки:

```bash
npm run build --workspace webapp
node --check server/index.js
node --check server/db.js
```
