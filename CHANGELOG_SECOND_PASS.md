# Second UX pass

- Возвращён общий скролл страницы, но добавлен стабильный scrollbar, чтобы меню не дёргалось при смене вкладок.
- Desktop-меню владельца/управляющего сделано компактным и без карточной обёртки: только вертикальный разделитель.
- Сотрудники редактируются кликом по строке; отдельная карточка редактирования убрана.
- Шаблоны чек-листов редактируются кликом по строке; список шаблонов стал компактным.
- Редактор пунктов чек-листа выровнен: поле, флаги и крестик находятся в одной строке на ПК.
- Залы и столы редактируются кликом по строке; строки и кнопки сделаны компактнее.
- В мобильной смене убраны комментарий к закрытию и экспорт.
- Мобильные брони переработаны: бронь создаётся нажатием на свободный стол, занятый стол открывает детали брони. Отдельный список броней с мобильной страницы удалён.
- Телефон гостя больше не блокирует создание брони, если его не указали.
- Мобильная страница задач очищена от лишней вложенности карточка-в-карточке.
- Нижняя мобильная навигация закреплена у края экрана и больше не выглядит отдельной плавающей карточкой.
