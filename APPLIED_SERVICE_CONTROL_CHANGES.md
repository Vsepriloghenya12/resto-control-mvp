# Applied service-control changes

## Что изменено

- Убрана функция товарных заявок из фронтенда:
  - удалён раздел "Заявки" из навигации сотрудника, менеджера и владельца;
  - удалено быстрое действие "Создать заявку";
  - удалён импорт и экран `Requests`;
  - удалён каталог `webapp/src/modules/requests`.

- Быстрые действия стали логичнее:
  - больше нет действий вида "Открыть заявки" внутри кнопки создания;
  - для сотрудника осталась основная кнопка "Сообщить о проблеме".

- Раздел задач переориентирован под контроль сервиса:
  - в мобильном интерфейсе раздел называется "Проблемы и задачи";
  - техзаявки переименованы в пользовательском интерфейсе в "Проблемы";
  - менеджер видит "Проблемы сотрудников".

- Экран "Сегодня" стал ближе к пульту смены:
  - подтягивает открытые проблемы сотрудника;
  - блок "Приоритет" показывает не только задачи, но и проблемы;
  - инвентаризация отображается как количество доступных бланков, а не абстрактное количество позиций.

- В задачи добавлен срок выполнения:
  - поле `Срок выполнения` в форме создания задачи;
  - срок отображается в списке задач у сотрудника и в админском списке.

- Убран дубль заголовка "Сегодня" в разделе задач сотрудника.

## Проверка

- `npx tsc --noEmit -p webapp/tsconfig.json` — успешно.
- Полная сборка `npm run build --workspace webapp` не завершилась из-за отсутствующей optional-зависимости Rollup в `node_modules`: `@rollup/rollup-linux-x64-gnu`. Это проблема текущей папки зависимостей, а не TypeScript-кода. Обычно лечится удалением `node_modules` и повторным `npm install`.

## Что оставлено намеренно

- Бэкенд-эндпоинты `/api/requests` и таблица `product_requests` пока оставлены для совместимости со старыми данными. Функция скрыта и удалена из фронтенда. Полное удаление из базы лучше делать отдельной миграцией, чтобы не сломать существующие snapshots/отчёты.
