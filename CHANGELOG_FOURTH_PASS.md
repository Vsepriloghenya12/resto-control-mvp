# Pass 4 — персонал, менеджер и база знаний

- Убрана карточка «Лента смены» из мобильного экрана персонала.
- Роль `manager` теперь отображается как «Менеджер» вместо «Управляющий».
- Мобильный кабинет менеджера сделан более прикладным: нижняя навигация ведёт в брони, заявки, задачи и базу знаний; тарифный баннер для менеджера не показывается.
- База знаний на мобильном теперь работает как список папок: сначала папки, внутри выбранной папки — документы.
- Новые папки и документы из кабинета владельца/менеджера теперь создаются с доступом для всех сотрудников по умолчанию, а после создания папки она автоматически выбирается для нового документа.
- Добавлены сообщения об успешном сохранении или ошибке при создании папок и документов.
