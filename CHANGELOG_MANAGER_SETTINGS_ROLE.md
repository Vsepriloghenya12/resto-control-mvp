# Manager settings role pass

- Перенесли управление рестораном в кабинет менеджера: сотрудники, чек-листы, номенклатура, залы/столы и база знаний теперь находятся в меню менеджера.
- Кабинет владельца упрощен до аккаунта, общего статуса ресторана и подписки.
- Обзор владельца больше не описывает настройку сотрудников, чек-листов, номенклатуры, залов и базы знаний как задачу владельца.
- Пульт менеджера теперь явно описывает, что менеджер ведет настройки ресторана и операционную смену.

Проверки:
- npm run build --workspace webapp
- node --check server/index.js
- node --check server/db.js
